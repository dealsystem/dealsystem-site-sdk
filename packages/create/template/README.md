# Meine Website

Diese Website läuft auf DealSystem. Gebaut und geändert wird sie mit einem KI-Agenten (zum Beispiel Claude
Code, Codex oder Cursor): Öffnen Sie diesen Ordner mit Ihrem Agenten und sagen Sie ihm, was Sie möchten.

Die Anleitung für den Agenten steht in `AGENTS.md`.

Was Sie selbst tun:

- die Anmeldung bei DealSystem im Browser bestätigen, wenn der Agent Sie darum bittet
- Impressum, Datenschutzerklärung und Firmendaten im CRM unter Eigene Website → Rechtliches eintragen
- Angebote und andere Sammlungen samt ihren Bildern im CRM unter CMS pflegen
- Fotos für die übrigen Seiten (z. B. ein Porträt) dem Agenten geben; er baut sie ein
- die Vorschau ansehen und sagen, ob die Seite veröffentlicht werden soll
